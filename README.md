# Chemistry Atlas

这是 Chemistry Atlas 五科知识库的第一版源码导出，包含总导航和五个独立站点：

- `hub/`：五科导航
- `organic/`：有机化学
- `inorganic/`：无机化学
- `physical/`：物理化学
- `analytical/`：分析化学
- `biochem/`：生物化学

每个目录都是一个可独立部署的静态网站，公开文件位于对应目录的 `dist/` 下，入口为 `dist/index.html`。

## 放入 GitHub Desktop

将这些目录和本文件复制到本地仓库：

`C:\Users\35515\Documents\GitHub\chemistry-atlas`

然后在 GitHub Desktop 中勾选所有变化，提交：

`Initial version of Chemistry Atlas`

最后点击 `Publish repository` 或 `Push origin`。

## 说明

这份导出不包含各个 ChatGPT Sites 项目的 Git 历史和部署元数据，只保留网站源码、图片、课件截图、词条数据和内容工作流文件，方便以后迁移到独立托管平台。
